Setup Info

* Make sure you have Node.js (LTS version) installed
* Clone the repo: https://github.com/masoncoyle/swe4663-project-management-system.git

Run the Backend
* In the VS Code terminal
    cd backend
    npm install
    npm run dev
* You should see "App listening on port 3000"

Run the Frontend
* Open a second terminal in VS Code
    cd frontend
    npm install
    npm run dev
* It runs at http://localhost:5173/api/health
* "Server running" when that is opened means the frontend and backend are connected
